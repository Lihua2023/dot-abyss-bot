## 0.2.0 绿衣刷取

在「绿衣」页可刷第 5 层 Very Hard 探索深度 10 的“森林披风”。开局先关 AUTO，检查首波自然掉落；无掉落时攒 4 能量放一次 FC 再检查。没有绿衣就等战败后重试；检出后可暂停保留战利品页，或开 AUTO 等胜利结算。胜利页不继续点击。绿衣设置保存在 `green_farm_settings.json`，不会修改深渊的 `config.json`。

真实掉落已由脚本检出并经用户手动通关确认；检出后 AUTO 通关还没有真实绿衣掉落实机验证。1600×900、1366×768、1280×720 通过缩放截图回放，实际低分辨率客户端和不同 DPI 仍未验证。起始界面与队伍要求见 [刷绿衣前必看](刷绿衣前必看.md)。

## 暂未适配或完成验证

- 纯日文原版、网页版、手机、模拟器、后台和最小化运行。
- 2K（例如 2560×1440）及其他分辨率；1600×900 也没有完成实机验证。
- 不同 Windows DPI/缩放比例、多显示器及不同标题栏/窗口布局。
- 30F 以上检查点的选择、滚动与后续完整流程。
- 代码满额、侵蚀满额/达到100%、战斗失败、门票或钥匙不足，以及 300 币金袋购买等边界情况。

程序虽包含部分边界处理逻辑，但这些场景未完成完整实机验证，暂不保证能可靠自动处理。遇到卡住、异常或资源不足，请按 F12 停止并手动处理。游戏更新后兼容性也需重新确认。

## 开始前的设置

1. 手动确认 AUTO 已打开、战斗速度为三倍速，当前队伍能自动战胜目标区间的敌人。
2. 在游戏内设为 1920×1080、窗口模式、60 FPS。保持游戏完整显示、无遮挡，不最小化；其他 DPI 不作兼容承诺。
3. 准备好门票/钥匙。运行会消耗游戏资源，失败也可能消耗资源。
4. 回到下图所示的深渊入口页，再启动脚本。先使用 30F 起点、推进10层、1轮，监督短段运行。

![推荐的深渊入口页面](assets/guide/recommended-start.png)

参考图只用于辨认入口布局，不要求货币、实绩、活动日期或角色与图中相同。图上的“探索再開”说明还有旧探索；首次使用建议先手动结束/归还旧探索，再回到入口。继续旧探索时，必须确认原起点与配置一致，不能把当前楼层当作新的起点。

## 使用步骤

完整解压 → 阅读“使用前先阅读.txt” → 按上述要求设置游戏并停在入口 → 双击“启动.cmd” → 设置检查点、推进层数和轮数 → 点击“保存并开始刷取” → 8秒内切回游戏。

**F7 暂停/继续，F12 停止，鼠标移到主屏角落紧急停止。** 切换应用会暂停点击，切回游戏后继续；运行中改变窗口大小或识别后移动窗口可能导致停止。

包内只保留两个 CMD：日常用“启动.cmd”，故障排查时可选用“自检.cmd”。首次请监督运行，不要将本工具当作无人值守保证。

详细说明见 [用户说明](release/README-用户版.md)。配置和日志位于 `%LOCALAPPDATA%\DotAbyss`；截图可能含账号信息，反馈时先遮挡，不要上传整个 runs、账号密码或完整账本。
