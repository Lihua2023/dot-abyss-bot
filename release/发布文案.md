# DOT ABYSS BOT 0.2.0

设置窗口有「深渊」「绿衣」两页，此版放大页签，并在绿衣页下方加入宝箱关卡图标参考。刷取起点是第 5 层 Very Hard「【衝撃】廃墟の階層／探索 深度 10」（第五层宝箱房）的任务详情页；地图与队伍设置可参考[刷绿衣视频](https://www.bilibili.com/video/BV1fx3y6pE7H/?spm_id_from=333.337.search-card.all.click&vd_source=c56a28fe802cb6e6086fb43a99455b0b)。实际选择以掉落列表含森林披风为准。首波自然掉落直接查，没有掉落则攒 4 能量放一次 FC 再查；无绿衣时等战败重试。检出后可保留战利品页暂停，或打开 AUTO 等到胜利结算，胜利页不继续点击。两页配置文件独立。

完整解压 `DotAbyss-0.2.0-win-x64.zip`，先读“使用前先阅读.txt”；使用绿衣页前另读“刷绿衣前必看.md”。源码包不能直接当免安装程序运行。校验值见 `SHA256SUMS.txt`。

适用 Windows x64 DMM 客户端，作者的中文汉化布局；实机主要在 1920×1080 窗口模式。绿衣检测与相关页面在 1600×900、1366×768、1280×720 的缩放截图回放一致，实际低分辨率窗口及不同 DPI 未验证。真实绿衣已由脚本识别，但检出后 AUTO 通关尚无真实出货实机验证。首次运行请在旁监督。
