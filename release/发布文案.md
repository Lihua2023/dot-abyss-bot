# Dot Abyss 深渊识图脚本 0.1.0-beta.2

Windows x64 免费测试版，解压即用，无需安装 Python 或 Codex。
识图和 OCR 在本机运行，不上传截图、不要求账号密码。
仅限非商业用途，禁止收费销售、付费代刷等商业使用；具体许可见附带 LICENSE。

下载请选 `DotAbyss-0.1.0-beta.2-win-x64.zip`，不要把 GitHub 自动生成的 Source code
压缩包当成可直接运行的程序。源码包为 `DotAbyss-0.1.0-beta.2-source.zip`。
下载后可用同页 `SHA256SUMS.txt` 核对文件。

开始使用：完整解压 → 自检.cmd → 打开游戏 → 环境检查.cmd → 只观察.cmd → 启动.cmd。
默认 30F 起步、推进 10 层、1 轮，首次请监督运行。F7 暂停，F12 停止。
运行会消耗游戏资源，请确认检查点、队伍和预算。

本次封装仅进行离线回放、OCR、Tk、完整性和独立路径检查，未重新进行游戏内测试，
也未在独立电脑实测。此前源码在作者电脑的 1920×1080 窗口模式完成过 30→80。
其他分辨率、DPI、界面语言和游戏更新后的兼容性尚未验证。
仅支持 Windows 前台可见窗口，不支持手机、后台和最小化运行。

配置和日志保存于 `%LOCALAPPDATA%\DotAbyss`；问题反馈请附版本、缩放、窗口尺寸、
界面语言、最后日志和已遮挡账号的截图。不要上传完整 runs、账号密码或账本。
