# Dot Abyss 0.1.1 · Windows 使用说明整理版

免费分享，仅限非商业用途。完整解压后，先阅读“使用前先阅读.txt”，再双击“启动.cmd”。“自检.cmd”仅为可选排错工具，无需每次运行。无需安装Python或Codex。

## 当前适用范围

- Windows x64，DMM GAME PLAYER游戏客户端。
- 作者当前的中文汉化补丁布局，部分按钮仍是日文；纯日文原版未适配。补丁具体版本尚未记录，其他补丁版本和布局未验证，本包不含汉化补丁。
- 游戏内1920×1080、窗口模式、60 FPS。提前手动打开AUTO，设为三倍速。
- 用户自行配队，并确认能自动打过设置的目标区间。脚本不会配队，也不保证战斗胜利。
- 当前实机验证基于30F起点。首次建议30F起步、推进10层、1轮，监督短段运行。

## 暂未适配或完成验证

纯日文、网页版、2K（如2560×1440）及其他分辨率（含1600×900）、不同Windows缩放/DPI、多显示器、手机、模拟器、后台/最小化运行，以及30F以上检查点，暂不保证可用。

代码满额、侵蚀满额/达到100%、战斗失败、门票或钥匙不足、300币金袋购买等边界场景未完成完整实机验证。程序虽包含部分处理逻辑，但目前不保证可靠自动处理，遇到卡住或异常请按F12停止并手动处理。游戏更新后兼容性也需重新确认。

## 开始前

确认AUTO三倍速、队伍和资源 → 回到深渊入口页（包内有“推荐起始界面.png”）→ 启动.cmd → 保存设置并开始 → 8秒内切回游戏。F7暂停/继续，F12停止；鼠标移到主屏角落也可紧急停止。

参考图只用于辨认入口布局，不要求货币、角色或实绩相同。“探索再開”表示有旧探索，首次建议先手动结束/归还旧探索再回入口；继续旧探索时，原起点须与配置一致。
