# Dot Abyss 0.2.1 使用说明

完整解压程序包后，先读“使用前先阅读.txt”，双击“启动.cmd”。窗口分为「深渊」和「绿衣」两页；两页分别保存配置。`自检.cmd` 是可选排错工具。

## 深渊页

基于 Windows x64、DMM GAME PLAYER、作者使用的中文汉化布局。作者本机 1920×1080 窗口模式曾从 30F 推进到 80F。先手动开 AUTO、三倍速，配好能打过目标楼层的队伍，从包内“推荐起始界面.png”所示页面启动。首次建议 30F 起点、推进 10 层、1 轮，有人在旁监督。其他窗口布局、DPI、纯日文、30F 以上检查点和边界场景不保证可用。

## 绿衣页

先阅读包内 [刷绿衣前必看](刷绿衣前必看.md)，按其中图片停在第 5 层 Very Hard「【衝撃】廃墟の階層／探索 深度 10」（第五层宝箱房）任务详情页，确认黄色「出撃」可见。地图与队伍设置可参考[刷绿衣视频](https://www.bilibili.com/video/BV1fx3y6pE7H/?spm_id_from=333.337.search-card.all.click&vd_source=c56a28fe802cb6e6086fb43a99455b0b)。绿衣页下方有宝箱关卡图标参考；实际选择以掉落列表含森林披风为准。队伍应能在没出绿衣时战败，以供脚本重试；选择检出后 AUTO 通关时也要能撑到胜利。开局脚本会关闭 AUTO，先检查自然掉落；若无掉落，攒 4 能量放一次 FC 再查。未检出时等战败重试。

检出绿衣后可选择保留战利品页暂停，或打开 AUTO 等到胜利结算。胜利页不会自动点击。真实绿衣曾被脚本检出并经用户手动通关确认；AUTO 通关分支尚未在真实绿衣掉落实机验证，请监督首次运行。

绿衣参数写入 `green_farm_settings.json`，深渊参数写入 `config.json`，均在 `%LOCALAPPDATA%\DotAbyss`；互不修改。日志和截图在其 `runs/green_farm` 下。绿衣图像识别在 1600×900、1366×768、1280×720 的缩放截图回放通过，实际低分辨率客户端窗口、不同 DPI 尚未验证。

## 通用操作

启动后 8 秒内切回游戏，并保持前台、窗口尺寸固定。F12 停止；鼠标移到屏幕角落也可紧急停止。深渊模式另有 F7 暂停/继续。运行会消耗游戏资源，请监督。遇到异常请先停止，反馈时只发送必要日志和遮挡账号信息的截图，不要公开整个 `runs` 目录。本程序不要求游戏账号密码，也不自动上传截图。
