# Dot Abyss 深渊识图脚本 0.1.1 使用说明

先阅读包内“使用前先阅读.txt”，按要求设置游戏，再双击“启动.cmd”。“自检.cmd”仅在需要排错时使用，不是每次启动的必经步骤。

## 适用范围和游戏设置

- Windows x64，DMM GAME PLAYER 游戏客户端；暂未适配网页版、手机、模拟器、后台或最小化运行。
- 作者当前使用的中文汉化补丁布局，部分按钮仍为日文。纯日文原版和其他汉化布局未适配或验证；补丁具体版本尚未记录，本包不含汉化补丁。
- 游戏内1920×1080、窗口模式、60 FPS。2K（例如2560×1440）、1600×900及其他分辨率未完成适配或验证；不同Windows缩放/DPI、多显示器不作兼容承诺。
- 提前手动开启AUTO，设置三倍速。自行配好能自动打过目标区间的队伍，脚本不配队、不保证战斗胜利。
- 当前实机验证基于30F起点；30F以上检查点未验证，其他起点也不作保证。首次建议30F起步、推进10层、1轮，并全程监督。

## 推荐起始画面

停在深渊入口页，再开启脚本。参考包内“推荐起始界面.png”。图中货币、角色、实绩和活动日期不要求相同。

![深渊入口参考图](../assets/guide/recommended-start.png)

“探索再開”表示有尚未结束的旧探索。首次使用建议先手动结束/归还旧探索，再回到入口；若继续旧探索，原起点应与配置一致，不能把当前层数当成新的起点。

## 日常使用

完整解压 → 阅读使用前说明 → 设置游戏并回入口 → 双击“启动.cmd” → 调整设置 → 保存并开始 → 8秒内切回游戏。

F7暂停/继续，F12停止，鼠标移到主屏角落紧急停止。切到其他应用暂停点击，切回游戏继续。需要改变窗口尺寸时，先停止再调整。识别后移动窗口也可能导致停止。

程序会消耗门票、钥匙或金币。请先确认资源和队伍；首次有人监督，不保证无人值守。

## 未完成验证的边界情况

代码满额、侵蚀满额/达到100%、战斗失败、门票或钥匙不足、300币金袋购买等，未完成完整实机验证。程序虽包含部分处理逻辑，但目前不保证能可靠自动处理，异常时按F12停止并手动处理。

游戏更新、不同UI布局、纯日文、其他分辨率/DPI和30F以上检查点也不保证可用。本次0.1.1只是说明及包内整理，并更新版本标识，未改识图、点击和刷取策略，未新增游戏内测试、离线回放或自检。以前的beta.2检查结果属于历史记录。

## 高级排错（可选）

普通用户不需要依次执行以下命令。确有需要时，在程序目录打开终端：

```powershell
.\DotAbyss.exe doctor             # 环境报告，不截图、不点击
.\DotAbyss.exe observe            # 等8秒后只观察并保存一张游戏画面，不点击
.\DotAbyss.exe reset-config       # 备份当前配置，再恢复默认配置
```

环境报告显示窗口尺寸和DPI，比例检查通过不等于其他分辨率已经适配。观察模式仍需游戏保持前台。自检仅证明本机依赖、模板、OCR和Tk能加载，不证明所有游戏流程可靠。

## 数据、更新与反馈

数据位于 `%LOCALAPPDATA%\DotAbyss`：config.json为用户配置，accounts为账号代号统计，runs为日志和截图。程序不要求账号密码，也不自动上传截图。每轮异步截图数量受上限保护，但历史记录不会自动删除，请在程序退出后自行清理不需要的runs子目录。

升级时先退出旧程序，把新包完整解压到新文件夹，通常会沿用原有用户配置。反馈提供版本、客户端和汉化布局、分辨率、系统缩放、检查点、最后日志及遮挡账号后的截图；不要上传整个runs或完整账本。
