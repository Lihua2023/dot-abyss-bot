# Dot Abyss 深渊识图脚本 0.1.0-beta.2

免费分享，仅限非商业用途。解压即可使用，无需安装 Python 或 Codex。
这是测试版：本次封装只做离线验收，没有进行新的游戏内测试。

## 使用

1. 将 ZIP 完整解压到一个文件夹，不要在压缩软件中直接运行 EXE。
2. 双击 `自检.cmd`。看到 `passed: true` 说明模板、OCR 和 Tk 初始化通过。
3. 打开 DMM 游戏客户端。首次建议采用游戏内 1920×1080 窗口模式，
   保持游戏完整显示、前台可见，不最小化、不遮挡。
4. 双击 `环境检查.cmd`，确认窗口能被找到，尺寸与 DPI 信息合理。
5. 可先双击 `只观察.cmd`，在 8 秒内切回游戏；它只保存一张游戏画面
   并输出识别结果，不点击。
6. 双击 `启动.cmd` 或 `DotAbyss.exe`，设置检查点、推进层数、轮数与优先级。
   默认检查点 30、推进 10 层、1 轮；请确认自己的检查点已解锁、队伍可用。
7. 点击“保存并开始刷取”，在 8 秒内切回游戏。首次请全程监督。

**F7 暂停/继续，F12 停止；鼠标移到主屏角落也可紧急停止。**
启动倒计时可用 F12 取消。OCR 期间停止检测可能延迟至当前识别返回，
本版本不承诺毫秒级热键响应。切换应用会暂停点击，切回游戏后继续。
运行中改变窗口尺寸、识别后移动窗口会停止；调整后重新启动。
停止后不会自动启动下一进程。设置与自动运行共用单实例锁。

## 策略与资源

- 默认每轮目标为“检查点 + 推进层数”，达到目标后归还结算。
- 默认颜色顺序黄、紫、蓝、红，路线顺序强敌、普通战斗、事件、恢复、商店、宝箱；可在设置中调整。
- 事件优先特殊战斗、代码；排除已识别的增加侵蚀选项。
- 恢复优先净化；侵蚀至少 60 时优先已识别且可达的恢复路线。
- 代码满额自动不领取；十层带回物品页直接取消。
- 商店按已识别价格、余额和确认页核对购买；包括既有的 300 币金袋分支。
  金袋购买尚未实机验证，本版本未对这一分支新增策略变更。
- 运行会消耗游戏门票、钥匙或金币。默认 1 轮不等于零资源消耗。
- 失败会清理结算并尝试重开，失败不计成功轮数；总运行时限和确认预算仍生效。

## 配置、记录、更新

数据保存于 `%LOCALAPPDATA%\DotAbyss\`：

- `config.json`：用户配置；首次从发行默认值生成，更新程序不覆盖。
- `accounts\<账号代号>\ledger.json`：本地统计，不需要游戏账号或密码。
- `runs\`：动作、识别日志和游戏截图；截图可能包含账号信息，请勿整体上传。

每轮运行最多保留 2000 张异步动作/恢复截图，队列最多 8 张；超限跳过可选截图。
此限制不自动删除历史运行；请定期在程序退出后清理不需要的 runs 子目录。
调整 `max_screenshots_per_run` 为 0 可关闭异步动作截图，观察和停机现场仍会保存。

配置损坏时双击 `恢复默认配置.cmd`，旧配置会另存备份。需要独立数据目录可用：

```powershell
.\DotAbyss.exe --data-dir 'D:\DotAbyssData' settings
```

更新：退出旧程序 → 解压新版到新文件夹 → 检查 SHA-256 → 自检 → 启动。
回滚：退出新版后启动保留的旧发行包。不同配置 schema 的版本需恢复对应备份。
删除程序文件夹不会删除 LocalAppData 中的数据。
