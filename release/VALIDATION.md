# 0.1.0-beta.2 验收范围

日期：2026-10-13。新发行包只执行离线检查，没有在游戏内测试，也没有独立电脑实测。
机器仍是原开发机；“独立目录”是路径和环境隔离测试，不能称作另一台干净电脑。

构建环境：Windows x64、CPython 3.12.14、PyInstaller 6.22.3。
完整依赖版本、模板和模型哈希、源代码提交见 `release.json`。

本地源码检查：85/85 截图回放通过；封装回归 7 项通过；真实数字 12345、
真实文本 DOT ABYSS、97 模板、Tcl/Tk 与隐藏 Tk 窗口初始化通过。
本地完整构建还执行冻结 EXE 的相同截图回放；具体数量和包内检查结果见
发行包的 `validation-results.json`，私有截图不随包公开。

发行隔离检查覆盖：

- 文件完整性和私人/开发文件排除。
- 复制到中文、空格路径，从其他工作目录启动。
- 移除 PYTHONHOME、PYTHONPATH、VIRTUAL_ENV，将 PATH 缩至 System32 后自检。
- EXE 中真实数字、文本 OCR，模型加载和 Tk 初始化。
- LocalAppData 写入默认配置、再次恢复时保留原配置备份。
- 坏配置写入错误日志、模板清单缺失时明确失败。

此前版本的实机证据：原电脑 1920×1080 窗口模式完成过 30→80、归还结算并结束。
新包增加了封装、路径、并发与记录防护；未重新确认游戏点击时序和热键实机响应。
不同分辨率、DPI、多显示器、完整日文布局、代码满额和金袋购买等不能据此保证。

发行包按测试版分享。后续使用者反馈仅作为补充证据，不把未测试条件写成已支持。
